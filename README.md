Online Survey System

1. Abstract

The Online Survey System is a Python-based project designed to collect feedback and opinions from users through online surveys. It allows users to answer questions and submit their responses. The system helps organize survey responses in a simple and efficient way.

2. Problem Statement

Collecting survey responses manually takes more time and makes data management difficult. This project aims to provide a simple digital method for collecting and managing responses.

3. Objectives

- To create online surveys.
- To collect user responses.
- To store survey data.
- To make feedback collection easier.

4. Technologies Used

- Programming Language: Python
- IDE: Visual Studio Code

5. Modules

- Survey Creation
- User Response Collection
- Response Management
- Result Display

6. Conclusion

The Online Survey System provides a simple way to collect and manage survey responses using Python.
